## 三、理论讲解

### 3.1 为什么要独立接口包

接口被多个包共用（`my_service_demo`、`my_action_demo`、后面 `my_delivery`）。

如果把 `.msg` 写在业务包里，业务包互相依赖会变成一团乱麻。

**惯例**：接口放独立包，只含定义，不含节点逻辑。

### 3.2 为什么接口包用 ament_cmake？

Python 业务包用 `ament_python`； 
接口包要调用 **rosidl 代码生成器**（生成 C++/Python 绑定），走 CMake 流程。

| 包类型 | 构建系统 | 用途 |
| ------ | -------- | ---- |
| `ament_python` | setuptools | 纯 Python 节点 |
| `ament_cmake` + `rosidl` | CMake | 接口包（.msg/.srv/.action） |

### 3.3 三种文件的语法

**.msg** —— 纯字段列表：

```text
string status
float32 battery
```

**.srv** —— 一条 `---` 分隔：

```text
string mode
---
bool success
string message
```

**.action** —— 两条 `---` 分隔三段：

```text
# goal（目标）
float32 distance
---
# result（结果）
bool success
float32 distance_traveled
---
# feedback（进度反馈）
float32 progress
```

### 3.4 关键配置

1. `CMakeLists.txt` 里 `rosidl_generate_interfaces(...)` 列出所有文件；
2. `package.xml` 里：
   - `buildtool_depend`：`ament_cmake`、`rosidl_default_generators`；
   - `member_of_group`：`rosidl_interface_packages`（**漏了会找不到接口**）；
3. 改了 `.msg` 字段后，**必须重新 colcon build**（不是只 source）。

### 3.5 import 的前提：先编译、再 source

```text
写 .msg  →  colcon build my_interfaces  →  source install/setup.bash
        →  才能 from my_interfaces.srv import SetMode
```

漏任何一步都是 `ModuleNotFoundError: my_interfaces`。

## 四、实操步骤（手把手）

> 本集开始新建包 `my_interfaces`（**接口包**，用 ament_cmake + rosidl），仓库对照：`code/src/my_interfaces/`。 

### 步骤 0 · 打开终端

Windows Terminal → Ubuntu。

**预期**：`<用户名>@<电脑名>:~$` 提示符。

### 步骤 1 · 创建接口包目录

```bash
cd ~/ros2_ws/src
ros2 pkg create my_interfaces --build-type ament_cmake
mkdir -p my_interfaces/msg my_interfaces/srv my_interfaces/action
```

**预期**：`ls my_interfaces` 显示 `msg  srv  action` 三个空目录。

### 步骤 2 · 写 msg/RobotStatus.msg

**设计动机**：看板要展示"状态文本 + 电量 + 模式 + 时间戳"。

完整内容（与仓库 `code/src/my_interfaces/msg/RobotStatus.msg` 一致）：

```text
# 机器人状态：上层看板用
# string status  状态文本：idle / moving / error 等
# float32 battery  电量百分比 0~100
# uint8 mode  模式编号 0=manual 1=auto 2=sport（与 SetMode 服务的合法模式一致）
# builtin_interfaces/Time stamp  时间戳

string status
float32 battery
uint8 mode
builtin_interfaces/Time stamp
```

路径：`~/ros2_ws/src/my_interfaces/msg/RobotStatus.msg`

**预期**：字段行与注释行分开；字段名小写 + 下划线（PEP 风格）。

### 步骤 3 · 写 srv/SetMode.srv

完整内容（与仓库一致）：

```text
# 设置模式：一问一答
# request
string mode
---
# response
bool success
string message
```

路径：`~/ros2_ws/src/my_interfaces/srv/SetMode.srv`

**预期**：只有一条 `---`，request 在上、response 在下。

### 步骤 4 · 写 action/MoveDistance.action

完整内容（与仓库一致）：

```text
# 前进指定距离：可反馈、可取消
# goal
float32 distance
---
# result
bool success
float32 distance_traveled
---
# feedback
float32 progress
```

路径：`~/ros2_ws/src/my_interfaces/action/MoveDistance.action`

**预期**：两条 `---`，三段顺序是 **goal → result → feedback**（注意不是 goal → feedback → result）。

### 步骤 5 · 写 CMakeLists.txt

完整内容（与仓库 `code/src/my_interfaces/CMakeLists.txt` 一致）：

```cmake
# my_interfaces：自定义接口包（ament_cmake + rosidl）
cmake_minimum_required(VERSION 3.8)
project(my_interfaces)

# C++17 为 Jazzy 常用基线
if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

find_package(ament_cmake REQUIRED)
find_package(rosidl_default_generators REQUIRED)
find_package(std_msgs REQUIRED)
find_package(builtin_interfaces REQUIRED)
find_package(geometry_msgs REQUIRED)

# 生成自定义接口：列出所有 .msg / .srv / .action
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/RobotStatus.msg"
  "srv/SetMode.srv"
  "action/MoveDistance.action"
  DEPENDENCIES std_msgs builtin_interfaces geometry_msgs
)

ament_export_dependencies(rosidl_default_runtime)
ament_package()
```

路径：`~/ros2_ws/src/my_interfaces/CMakeLists.txt`

**预期**：三个接口文件路径写对；`DEPENDENCIES` 含 `builtin_interfaces`（RobotStatus 用到）。

### 步骤 6 · 写 package.xml

完整内容（与仓库一致）：

```xml

<package format="3">
  <name>my_interfaces</name>

  <description>S1 模块3：自定义 msg / srv / action 接口包</description>
```

## 五、关键 API / 命令详解

| 名称 | 作用 |
| ---- | ---- |
| `rosidl_generate_interfaces(包名 文件... DEPENDENCIES ...)` | 声明要生成哪些接口 |
| `find_package(rosidl_default_generators REQUIRED)` | 引入代码生成器 |
| `member_of_group rosidl_interface_packages` | 声明这是接口包（漏了找不到） |
| `ros2 interface show <类型>` | 查看字段 |
| `ros2 interface list` | 列出所有接口 |
| `ros2 interface package my_interfaces` | 列出某包的接口 |

Python 侧使用（下一集才写，先看一眼）：

```python
from my_interfaces.srv import SetMode
from my_interfaces.action import MoveDistance
from my_interfaces.msg import RobotStatus
```

⚠️ 前提：`colcon build --packages-select my_interfaces` **且** source 过。

## 六、常见坑

| 报错 / 现象 | 原因 | 解法 |
| ----------- | ---- | ---- |
| `ModuleNotFoundError: my_interfaces` | 没编译接口包，或没 source | 先 build my_interfaces，再 source 两层 |
| `ros2 interface show my_interfaces/...` 找不到 | 同上，或 package.xml 漏 `member_of_group` | 补 `member_of_group`，重新 build |
| `rosidl_generate_interfaces` 报文件不存在 | 路径拼写错 | 核对 `"msg/RobotStatus.msg"` 等 |
| 改了 .msg 字段但代码行为没变 | 必须重新 colcon build（生成代码） | `colcon build --packages-select my_interfaces` |
| 字段名用了保留字/大写 | rosidl 命名不合法 | 全小写 + 下划线，如 `distance_traveled` |
| `.action` 顺序写错 | 把 feedback 放第二段 | 顺序固定：goal `---` result `---` feedback |
| 在 ament_python 包里直接放 .msg | 不会生成接口 | 接口必须独立 ament_cmake 包 |
