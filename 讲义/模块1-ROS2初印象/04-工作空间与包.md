## 三、理论讲解

### 3.1 工作空间：四个目录各干各的

```text
~/ros2_ws/
├── src/          ← 你写的源码（唯一需要你维护的）
├── build/        ← 编译中间产物（可删）
├── install/      ← 安装结果（source 这里的 setup.bash）
└── log/          ← 编译日志（出错先看这里）
```

| 目录 | 谁创建 | 能不能删 |
| ---- | ------ | -------- |
| `src/` | 你 | 别删，这是你的代码 |
| `build/` | colcon | 能删，下次 build 重建 |
| `install/` | colcon | 能删，但删后要重新 build + source |
| `log/` | colcon | 能删，排错时需要 |

**口诀**：源码进 `src`，编译完去 `install` 找 setup.bash，报错去 `log` 看。

### 3.2 包 = 最小交付单元

一个**包（Package）**把代码、依赖、元数据打成一个可交付的整体。类比：

> 一盒零件 + 说明书（`package.xml`）+ 安装说明（`setup.py`）。

规则：包名**小写字母 + 数字 + 下划线**，如 `my_first_pkg`。

| 非法 | 合法 |
| ---- | ---- |
| `MyPkg` | `my_pkg` |
| `my-pkg` | `my_first_pkg` |
| `my pkg` | `my_robot_demo` |

### 3.3 ament_python vs ament_cmake

| 构建类型 | 用在哪 | 本课 |
| -------- | ------ | ---- |
| **`ament_python`** | 纯 Python 包 | 你的节点包都用它 |
| `ament_cmake` | C++ 或接口包 | 模块 3 的 `my_interfaces` |

Python 包靠 `setup.py` 声明；C++ 包靠 `CMakeLists.txt`。

### 3.4 四件套分工

| 文件 | 干什么 | 类比 |
| ---- | ------ | ---- |
| `package.xml` | 包名、版本、**依赖**、构建类型 | 零件说明书 |
| `setup.py` | 安装规则 + **入口可执行** | 安装向导 |
| `setup.cfg` | 安装脚本目录 | 说明书附录 |
| `resource/<包名>` | ament 资源索引标记 | 盒子上的条形码 |

**最容易错的是 `setup.py` 的 `entry_points`**：它决定 `ros2 run my_first_pkg hello_node` 能不能找到程序。

### 3.5 节点文件放哪？

```text
src/my_first_pkg/
├── my_first_pkg/          ← Python 包目录（和包同名）
│   ├── __init__.py        ← 告诉 Python"这是个包"
│   └── hello_node.py      ← 节点源码
```

生成后 `hello_node.py` 只是占位，下一集我们写成真正的 Hello 节点。

## 四、实操步骤（手把手）

> 本集开始新建包 `my_first_pkg`。仓库对照：`code/src/my_first_pkg/`。 

### 步骤 0 · 打开终端

Windows Terminal → **Ubuntu**。

**预期**：提示符 `<用户名>@<电脑名>:~$`。

### 步骤 1 · 创建工作空间

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src
pwd
```

> 工作目录：`~/ros2_ws/src`

**预期**：`pwd` 显示 `/home/laoding/ros2_ws/src`。

> 注意：必须在 **`src/`** 下建包，不要在 `~/ros2_ws` 根目录。

### 步骤 2 · 生成包

```bash
ros2 pkg create my_first_pkg --build-type ament_python --node-name hello_node
```

> 工作目录：`~/ros2_ws/src`

含义：

| 参数 | 作用 |
| ---- | ---- |
| `--build-type ament_python` | 纯 Python 包 |
| `--node-name hello_node` | 顺带生成名为 hello_node 的节点文件 |
| `my_first_pkg` | 包名（最后一项） |

**预期**：输出类似

```text
going to create a new package
...
package created: .../my_first_pkg
```

### 步骤 3 · 查看生成结构

```bash
cd ~/ros2_ws
find src/my_first_pkg -type f | sort
```

或（若已装 tree）：

```bash
# 安装命令：sudo apt update && sudo apt install tree -y
tree src/my_first_pkg
```

**预期**：至少看到

```text
src/my_first_pkg/package.xml
src/my_first_pkg/setup.py
src/my_first_pkg/setup.cfg
src/my_first_pkg/resource/my_first_pkg
src/my_first_pkg/my_first_pkg/__init__.py
src/my_first_pkg/my_first_pkg/hello_node.py
```

### 步骤 4 · 对照 package.xml

打开 `~/ros2_ws/src/my_first_pkg/package.xml`。教学版与仓库 `code/src/my_first_pkg/package.xml` 一致：

```xml
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>my_first_pkg</name>
  <version>0.1.0</version>
  <description>S1 入门包：Hello ROS2 节点（模块1）</description>
  <maintainer email="lddzwxy@gmail.com">laoding</maintainer>
  <license>Apache-2.0</license>

  <depend>rclpy</depend>

  <test_depend>ament_copyright</test_depend>
  <test_depend>ament_flake8</test_depend>
  <test_depend>ament_pep257</test_depend>
  <test_depend>python3-pytest</test_depend>

  <export>
    <build_type>ament_python</build_type>
  </export>
</package>
```

逐段看：

| 字段 | 含义 |
| ---- | ---- |
| `<name>` | 这个包叫什么 |
| `<depend>rclpy</depend>` | 运行依赖：ROS2 的 Python 客户端库 |
| `<test_depend>` | 测试工具依赖 |
| `<build_type>ament_python` | 纯 Python 包 |

**预期**：能在文件里指出"包名叫什么、依赖什么"两行。

### 步骤 5 · 对照 setup.py 入口

打开 `~/ros2_ws/src/my_first_pkg/setup.py`，重点看 `entry_points`（与仓库 `code/src/my_first_pkg/setup.py` 一致）：

```python
# ament_python 包构建配置：声明包名、入口可执行
from setuptools import find_packages, setup

package_name = 'my_first_pkg'

setup(
    name=package_name,
    version='0.1.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        # ament 资源索引（标记包已安装）
        ('share/ament_index/resource_index/packages',
         ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='laoding',
    maintainer_email='lddzwxy@gmail.com',
    description='S1 入门包：Hello ROS2 节点',
    license='Apache-2.0',
    tests_require=['pytest'],
    entry_points={
        'console_scripts': [
            # 可执行名 = 包内模块:main 函数
            'hello_node = my_first_pkg.hello_node:main',
        ],
    },
)
```

**入口三段含义**：

```text
hello_node  =  my_first_pkg.hello_node : main
   ↑                  ↑                  ↑
可执行名          模块路径(.py)            函数名
```

`ros2 run my_first_pkg hello_node` 就是按这三段去调用 `main()`。

**预期**：字符串三段与实际文件路径一致。

### 步骤 6 · 看 setup.cfg 与 resource

`setup.cfg`（与仓库一致）：

```ini
[develop]
script_dir=$base/lib/my_first_pkg
[install]
install_scripts=$base/lib/my_first_pkg
```

作用：告诉 setuptools 把可执行脚本装到 `lib/my_first_pkg/`——`ros2 run` 会来这里找。

`resource/my_first_pkg` 是**空占位文件**，让 ament 索引知道"这个包装好了"。删了它，包会不可见。

**预期**：`ls -l src/my_first_pkg/resource/my_first_pkg` 文件存在。

### 步骤 7 · 知道 hello_node.py 现在还是占位

```bash
cat ~/ros2_ws/src/my_first_pkg/my_first_pkg/hello_node.py
```

**预期**：能看到一个最小节点模板（打印或空转）。**本集不改它**，下集替换成真正的 Hello 节点。

### 步骤 8 · （可选）目录总览

```bash
cd ~/ros2_ws
find src/my_first_pkg -type f | sort
```

**预期**：6 个文件，路径与步骤 3 一致。

## 五、关键 API / 命令详解

| 名称 | 作用 |
| ---- | ---- |
| `mkdir -p ~/ros2_ws/src` | 创建工作空间源码目录 |
| `ros2 pkg create my_first_pkg --build-type ament_python --node-name hello_node` | 生成 Python 包骨架 |
| `ros2 pkg create <package_name> --build-type ament_cmake ...` | 生成 C++ / 接口包（模块 3） |
| `find src/my_first_pkg -type f \| sort` | 列出包内全部文件 |
| `package.xml` | 包元数据 + 依赖声明 |
| `setup.py` | 安装规则 + `entry_points` 入口 |
| `setup.cfg` | 可执行安装位置 |
| `resource/<包名>` | ament 资源标记 |
| `entry_points['console_scripts']` | 定义 `ros2 run` 的可执行名 |
| `rclpy` | ROS2 Python 客户端库（`<depend>` 里声明） |

## 六、常见坑

| 报错 / 现象 | 原因 | 解法 |
| ----------- | ---- | ---- |
| `ros2 pkg create` 后 `ros2 pkg list` 看不到包 | 还没编译 / 没 source | 下集 `colcon build` 后 source |
| 包建在 `~/ros2_ws` 根下 | 忘了进 `src/` | 移动到 `src/` 再操作 |
| 包名用了大写或横线 | 违反命名规则 | 只用小写+下划线 |
| `Executable 'hello_node' not found` | `entry_points` 写错 | 核对三段字符串与文件路径 |
| `Package 'my_first_pkg' not found` | 未安装 / 未 source | 编译后 `source install/setup.bash` |
| `resource/` 缺失导致包不可见 | 误删占位文件 | 恢复 `resource/my_first_pkg` 空文件 |
| `find` / `tree` 命令不存在 | 没装 | `sudo apt install -y tree` |
| `setup.cfg` 包名写成别的 | 复制模板没改 | 两处都要与包名一致 |
