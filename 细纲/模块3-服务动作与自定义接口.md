# 模块 3 · 服务、动作与自定义接口（细纲 · 6 集）

> 目标：会设计并实现 Service / Action，能建自定义接口包。 
> 前置：模块 2 熟练 Topic；会 colcon 闭环。 
> 产出包：`my_interfaces`（ament_cmake 接口包）、`my_service_demo`、`my_action_demo`。 
> 顺序原则：**先建自定义接口（3.2）再写 Server/Client（3.3/3.5）**，解决"先用到再学"。

## 3.1 Service：一问一答

| 字段 | 内容 |
| ---- | ---- |
| 本集目标 | 理解请求/响应模型；会调用现成 Service |
| 开场演示 | turtlesim `/spawn`、`/clear`、`/set_pen`；`ros2 service list/call` |
| 知识点 | ① Service 类型 = `.srv`（request `---` response）② 同步调用会阻塞 ③ 适合低频、要结果的请求 ④ 与 Topic 对比 |
| 跟做步骤 | **1** `ros2 run turtlesim turtlesim_node`<br>**2** `ros2 service list` / `ros2 service type /spawn`<br>**3** `ros2 interface show turtlesim/srv/Spawn`<br>**4** `ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.0, name: 'turtle2'}"`<br>**5** `ros2 service call /turtle1/set_pen turtlesim/srv/SetPen "{r: 255, g: 0, b: 0, width: 3}"` |
| 关键命令 | `ros2 service list/type/call`、`ros2 interface show` |
| 常见坑 | 在回调里同步 `call` 另一个 Service 可能死锁；把高频控制放到 Service |
| 预期输出 | 多出 turtle2；画笔变红 |
| 小作业 | 调用 `/clear` 并观察；写出 Spawn 的 request 字段 |
| 下集预告 | 系统里的接口不够用？自己定义 .msg/.srv/.action |

## 3.2 自定义 .msg / .srv / .action

| 字段 | 内容 |
| ---- | ---- |
| 本集目标 | 建 `my_interfaces` 接口包，生成三种自定义接口 |
| 开场演示 | `ros2 interface show my_interfaces/msg/RobotStatus` 等三条命令 |
| 知识点 | ① 接口包推荐独立 ② `ament_cmake` + `rosidl_generate_interfaces` ③ msg/srv/action 语法 ④ `package.xml` 的 `member_of_group rosidl_interface_packages` ⑤ **必须先编译 source 才能 import** |
| 跟做步骤 | **1** `cd ~/ros2_ws/src && mkdir -p my_interfaces/{msg,srv,action}`<br>**2** 写 `msg/RobotStatus.msg`：`string status` + `float32 battery` + `builtin_interfaces/Time stamp`（或 std_msgs/Header）<br>**3** 写 `srv/SetMode.srv`：request `string mode` --- response `bool success` + `string message`<br>**4** 写 `action/MoveDistance.action`：goal `float32 distance` --- result `bool success` + `float32 distance_traveled` --- feedback `float32 progress`<br>**5** 写 `CMakeLists.txt`：`find_package(rosidl_default_generators REQUIRED)` + `rosidl_generate_interfaces(${PROJECT_NAME} "msg/RobotStatus.msg" "srv/SetMode.srv" "action/MoveDistance.action")`<br>**6** 写 `package.xml`：`buildtool_depend ament_cmake`，`depend` rosidl 相关，`member_of_group rosidl_interface_packages`<br>**7** `colcon build --packages-select my_interfaces`<br>**8** source 后 `ros2 interface show my_interfaces/msg/RobotStatus` |
| 关键 API | `rosidl_generate_interfaces`、`ros2 interface show/list` |
| 常见坑 | ① 没编译就 import（ImportError）② 忘 member_of_group ③ 字段名用了保留字 ④ 改了接口没重新 colcon |
| 预期输出 | 三条 `interface show` 都能打印字段 |
| 小作业 | 给 RobotStatus 增加 `uint8 mode` 并重新编译验证 |
| 下集预告 | 用 SetMode 写 Service 服务端/客户端 |

## 3.3 Service Server / Client

| 字段 | 内容 |
| ---- | ---- |
| 本集目标 | 实现 `/set_mode` 服务端与客户端（同步+异步） |
| 开场演示 | client 发模式，server 日志与 response success |
| 知识点 | ① `create_service` / `create_client` ② 回调签名 `(request, response)` ③ `call_async` + spin_until ④ 同步阻塞 vs 异步 |
| 跟做步骤 | **1** 建包 `my_service_demo`（ros2 pkg create --build-type ament_python）<br>**2** `package.xml` 增加 `my_interfaces`、`rclpy` 依赖<br>**3** 写 `service_server.py`：`create_service(SetMode, '/set_mode', cb)`，校验 mode 合法性填 response<br>**4** 写 `service_client.py`：`create_client`，`wait_for_service`，`call_async`，写 2 种调用示例<br>**5** entry_points 两条<br>**6** colcon build + source<br>**7** 终端A run server，终端B run client；`ros2 service list` 观察 |
| 关键 API | `create_service`、`create_client`、`call_async`、`spin_until_future_complete` |
| 常见坑 | ① 未 source 新 install → `ModuleNotFoundError: my_interfaces` ② client 没 `wait_for_service` 就 call ③ 在节点回调里同步 call 卡死 |
| 预期输出 | client 收到 success/message；非法 mode 时 success=false |
| 小作业 | 增加模式 `sport`，非法时 message 写明允许列表 |
| 下集预告 | 长时任务怎么办？Action |

## 3.4 Action：长时任务

| 小作业 | 写出"导航到点""开灯""电量查询"各用哪种通信 |

## 3.5 Action Server / Client

| 字段 | 内容 |
| ---- | ---- |
| 本集目标 | 实现前进 N 米的 Action：反馈 progress、可取消 |
| 开场演示 | goal=5m，进度 0.2…1.0；第二轮中途 cancel |
| 知识点 | ① `ActionServer`/`ActionClient` ② execute 回调与 goal_handle ③ `publish_feedback` ④ `is_cancel_requested` / `canceled` ⑤ result 回填 |
| 跟做步骤 | **1** 建包 `my_action_demo`<br>**2** 写 `move_server.py`：定时模拟里程，feedback=progress，检查取消，返回 distance_traveled<br>**3** 写 `move_client.py`：send_goal、回调收 feedback、示例 cancel<br>**4** 依赖 my_interfaces，entry_points，colcon build，source<br>**5** 双终端运行；观察进度与取消 |
| 关键 API | `ActionServer`、`ActionClient.send_goal`、`goal_handle.publish_feedback`、`goal_handle.canceled()` |
| 常见坑 | ① 忘记处理取消请求 ② 未编译接口就跑 ③ execute 里阻塞太久不回反馈 |
