## 5.2 ros2 bag 录放

| 字段 | 内容 |
| ---- | ---- |
| 本集目标 | `ros2 bag record/play/info` 会保存与复现 |
| 开场演示 | 录 20 秒 cmd_vel，关掉节点后 play，sub 仍有数据 |
| 知识点 | ① rosbag2 ② 录指定话题 ③ play 控速 `--rate` ④ info 看消息数 |
| 跟做步骤 | **1** 发布节点运行中<br>**2** `ros2 bag record -o my_bag /cmd_vel`，运行几秒 Ctrl+C<br>**3** `ros2 bag info my_bag`<br>**4** 停 pub，`ros2 bag play my_bag`，sub 收到<br>**5** `ros2 bag play my_bag --rate 2` |
| 关键命令 | `ros2 bag record/play/info` |
| 常见坑 | 用成 ROS1 `rosbag`；录了一堆无关话题占空间；没 source 环境找不到包 |
| 预期输出 | info 显示消息数>0；play 时 echo 有数据 |
| 小作业 | 录 `/cmd_vel` + `/odom`，play 并用 rqt_plot 对照 |
| 下集预告 | 日志怎么写才有用？ |
